# Mundo Aberto

Camada persistente do universo do futebol. O mundo continua evoluindo enquanto o jogador joga.

## Regra de dados
- Futebol real: somente dados verificáveis.
- Sem fonte: `pending_official`.
- Eventos, notícias e transferências sintéticas ficam marcados como simulação do jogo.
- O Mundo Aberto não altera silenciosamente dados oficiais de clubes.
