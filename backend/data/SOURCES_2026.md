# WPG — Coleta de jogadores 2026

## Hierarquia de fontes

1. **CBF** — fonte primária para identidade/registro competitivo, clube atual, nome/apelido e dados individuais quando publicados.
2. **API-Football** — enriquecimento de temporada/estatísticas e identificadores externos; requer `API_FOOTBALL_KEY`.
3. **FootyStats** — fonte auxiliar de estatísticas de temporada. Não é autoridade de registro de elenco.

## Regra

Nenhum dado de API externa é tratado como “oficial CBF”. Campos conflitantes permanecem pendentes para revisão.

## Temporada

2026. A coleta é versionada; não substituir registros históricos silenciosamente.
